① 组件词（11）

页面上那些"有名字的零件"。每个 demo 都是真的，随便点、随便悬停。

1. Hover 悬停

鼠标停上去时元素的变化——变色、浮起、加阴影。不用点，滑过去就行。

把鼠标滑到我身上

沟通话术："这个卡片 hover 时浮起 + 加阴影"

2. Popover 弹出层

点按钮弹出的小浮层。点外面就消失，无红绿灯、无叉——正是你描述过的那个。

我是一个 Popover

试试点面板外的任何地方——我会自动消失。

默认行为：点外部关闭 · Esc 关闭。shadcn 里就叫 Popover

3. Tooltip 悬停提示

纯提示，不能交互。和 Popover 的区别：Tooltip 只能用眼睛看，Popover 里面能放按钮。

我是 Tooltip，1 秒后自己消失

口诀：能点的用 Popover，只看看的用 Tooltip

4. Modal / Dialog 大弹窗

居中大弹窗 + 背景变暗。必须处理完才能干别的（或点背景关闭）。比 Popover 郑重。

那层变暗的膜本身也有名字，见第 10 个词 Backdrop

5. Toast 飘过的通知

角落里弹出来、几秒后自己消失的通知。不用点任何东西。

shadcn 里用 Sonner 实现，名字不同东西相同

6. Drawer / Sheet 抽屉

从屏幕边缘滑出来的面板，手机端最常用。

shadcn 里叫 Sheet；手机版布局里侧边栏常变成它

7. Dropdown 下拉菜单

点一下列出一串选项。长得很像 Popover，但它专用于"选一项"。

重命名
复制路径
删除…

8. Accordion 折叠面板

点标题展开、再点收起。FAQ 页面的标配。

什么是组件？▾
页面上可复用的最小功能件。一个按钮、一个弹窗，都是组件。
为什么词表这么重要？▾
一个词压缩一段话，且全行业语义一致——人和 AI 都听得懂。

9. Skeleton 骨架屏

数据还没到时，先用灰色闪光占位，而不是白屏傻等。

加载体验三兄弟：Skeleton（占位）→ Toast（通知）→ Popover（交互）

10. Backdrop / Overlay 背景膜

让背景变暗/模糊的那层膜，让弹层内容凸显出来。刚开的 Modal 背后就是它。

11. Disabled · Active · Focus 三态

Disabled 不可点（灰）· Active 正在被按下 · Focus 被键盘/点击选中（描边）。

16. Container 限宽容器

把内容锁在一个最大宽度里居中，大屏幕上不至于一行字拉到三米长。

17. Section 大段区块

页面的一大段：头图区（Hero）、功能介绍区、页脚。Layout 就是一个个 Section 摞起来的。

🖼️ 一张图片块

③ 响应式词（5）

同一棵嵌套树，在不同屏宽下换折法。

19-20. Responsive + Breakpoint 响应式 + 断点

拖动滑杆模拟屏幕变窄——过了断点（700px）卡片自动从 3 列变 1 列。页面还是同一个页面。

桌面版和手机版不是两个页面，是同一棵树换了折法

21. Mobile-first 手机优先

先做手机版（最窄、最简单），再往大屏加列、加侧边栏。现在的默认做法。

📱 手机版
1 列，一切竖排
→ 加宽 →
🖥️ 桌面版
加列、加侧边栏、加悬浮

22. Fluid / Fixed 流动 / 固定

Fluid 按百分比跟着屏幕撑，Fixed 写死像素。现代做法：外层 Fluid + 内层 Container 限宽。

Fluid：随窗口伸缩
Fixed: 130px
